## Проблемы по важности

**П1 (средняя). Кнопки первого экрана VoiceOver не называет кнопками.**
`lib/widgets/ds_button.dart:224-231` — голый `GestureDetector`, без `Semantics(button: true)`. VoiceOver прочтёт «Начать», а не «Начать, кнопка»; так у всех `DsButton` в приложении (было и до этой работы, но в ADR/задаче заявлено как сделанное). Тест `welcome_motion_test.dart:62-63` проверяет только заголовок и ссылку.
Правка: обернуть в `Semantics(button: true, enabled: !_disabled, child: …)` (и для выключенной кнопки, строка 222) + одна проверка `isButton` в тесте.

**П2 (низкая–средняя). Отклик «успех» там, где ничего не отправлено.** `chat_view_screen.dart:705`
- правка сообщения (ветка `editing`, 716-722): раньше при правке не жужжало совсем, теперь «успех» — даже если правка не удалась;
- нет чата (`id == null`, 707-712): жужжит, хотя ничего не ушло;
- отправка не удалась — жужжит (это в ADR записано как цена).
Правка: перенести строку 705 ниже ветки `editing` (перед `final reply = …`, 723) — тогда отклик только при настоящей отправке сообщения.

**П3 (низкая). Двойное нажатие по ссылке открывает её дважды.** Раньше двойное нажатие забирал жест сердечка; теперь (`chat_view_screen.dart:3259-3263`) ссылка, цитата и карточка ссылки срабатывают на каждое нажатие. ADR это допускает («срабатывает сама ссылка»), но два открытия браузера подряд — заметно. Проверить на телефоне; если мешает — в обработчике ссылки не открывать повторно в течение 300 мс.

**П4 (низкая). Дуга «Настраиваем» перезапускается с нуля.** `setting_up_screen.dart:74`: `_spin.repeat()` вызывается при каждой смене зависимостей (экран читает весь `MediaQuery`, строка 108) — при повороте/смене размера окна дуга прыгнет в начало. За 1,5 с почти не встретится.
Правка: `else if (!_spin.isAnimating) _spin.repeat();` — как уже сделано для знака в `welcome_screen.dart:48`.

**П5 (низкая). `_tapBubble` и сообщение без `id`.** `chat_view_screen.dart:819`: `_tappedId == m.id` истинно, если оба `null` (`_Msg.id` — `String?`, строка 156) — тогда сердечко поставилось бы с первого нажатия. У сообщений из базы `id` есть (`:2658`), а действие разрешено только при `wireId != null` (2372), так что на деле не встретится.
Правка: `if (m.id != null && _tappedId == m.id)`.

**П6 (низкая, косметика). Закрытие шторки едет по другой кривой.** Раньше вниз шла по `DsMotion.exit` (`reverseCurve`), теперь сдвиг в `adaptive.dart:361-364` берёт `emphasized` в обе стороны; фон по-прежнему гаснет по `exit`. За 120 мс почти не видно. Правка не обязательна.

**П7 (замечание, не ошибка). Единственное появление строк может пройти незамеченным.** Флаг общий на всё приложение: если первый список построился под экраном блокировки или первым открыли не список чатов — появление «потрачено», и до перезапуска его больше не будет. Невидимым ничего не остаётся. Параметры `index` / `maxStagger` у `DsAppear` теперь не используются (`ds_motion.dart:20,23`) — можно убрать позже (KISS).
