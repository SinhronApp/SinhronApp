## 3. Проверить на телефонах после 0.12.0 (все уже на 0.12.0)
- Приложение открывается без ввода слов, старые чаты на месте; в каждом старом чате написать в обе стороны, реакция.
- Фото и файл в личный чат и в группу.
- Звонок 1:1: выключить/включить микрофон; видеозвонок: камера вкл/выкл, смена камеры; показ экрана — начать, остановить, отменить окно.
- Групповой видеозвонок на 3+ телефонах, 5 минут. Во время звонка Wi‑Fi → сотовая: звонок восстанавливается.
- Звонок на заблокированный iPhone при закрытом приложении — имя звонящего; Android — звонит при закрытом приложении.
- Push при закрытом приложении на iPhone и Android — «Имя: текст».
- Группа: создать, добавить человека, удалить его (у него «Вас удалили»); создатель выходит — админ следующий.
- Группа, плохая связь: добавить человека и сразу «в самолёте»; после сети чат работает.
- Новое устройство по QR: Face ID, адрес аккаунта для сверки, вся история; тот же код второй раз — «уже использован».
- Новый телефон по 24 словам, пока старый в сети — чаты открылись. Потерянный телефон: сначала войти на новом, потом отключить старый.
- Отключение устройства (Face ID; «Отмена» — осталось); после отключения сообщения и push с текстом приходят на оставшиеся.
- Восстановление из копии (iCloud / Google Диск): чаты, сообщения, медиа на месте.
- Face ID спрашивают: «Удалить аккаунт», «Выйти», «Отключить», выключение блокировки, «Вставить из связки ключей».
- «Пригласить» — короткая ссылка `…/i/…` открывается на другом телефоне.
- «Создать копию сейчас» — без ошибок.
