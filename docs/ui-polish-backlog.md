# Sinhron · бэклог полировки клиента («премиум, а не для гиков»)

> **Создано:** 2026-10-13. Основа — аудит `client_flutter/lib` (граф graphify + полный обход экранов). Цель: ощущение уровня Telegram / iMessage. Это план, не сделанная работа; статус по пунктам — в `docs/status.md`.

## 0. Честная картина (аудит)

**Что хорошо:** свой дизайн-слой без Material (Geist, токены светлой/тёмной темы, ~18 Ds-виджетов), цепочки пузырей с правильными радиусами, градиентные исходящие, свайп-действия, pull-to-refresh, Cupertino-переходы, реальные данные в списке чатов, чате, медиа и звонках.

**Что выдаёт «прототип»:**
- **Производительность чата:** `ListView(children: …)` строит все сообщения сразу, история грузится целиком (`limit: null`), чат открывается на самом старом сообщении; `setState` на каждую букву перерисовывает весь чат; `MediaQuery.of` в каждом пузыре → каждый кадр анимации клавиатуры перерисовывает все пузыри; нет ключей у пузырей и строк, нет `RepaintBoundary`, картинки декодируются в полном размере.
- **Фальшь в интерфейсе:** фильтры чатов не фильтруют; свайп-действия ничего не делают; поиск, контакты, история звонков, инфо о контакте, меню сообщения («Pin», «Select») — макеты; при ошибке загрузки показываются демо-чаты; имя «Vera Kuznetsova» и бейдж «5» зашиты в код; галочки всегда одна; блокировка приложения — картинка без Face ID; настройки — переключатели, которые никуда не сохраняются; «Demo gallery» доступна в обычных настройках.
- **Нет «ощущения»:** ноль хаптики, ноль `Hero`, нет пружинной физики, нет анимации появления сообщений, нет кнопки «вниз», нет разделителя «Непрочитанные».
- **Дизайн-система не используется:** 589 стилей текста собраны вручную вместо 11 токенов, 760 «сырых» цветов, 242 самописных `CustomPainter`-иконки, токены теней не используются.
- **Доступность и язык:** нет `Semantics`, нет поддержки крупного шрифта, нет локализации — все строки английские, хотя аудитория русскоязычная.
