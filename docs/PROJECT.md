### Phase 2 — Rust Core + Server + Sync (функционально закрыта)

**6 Rust крейтов** (5 client + 1 server):

| Крейт | Назначение | LOC |
|---|---|---|
| `sinhron_crypto` | BIP-39, HKDF, Ed25519, X25519, openmls обёртки | ~500 |
| `sinhron_storage` | rusqlite + SQLCipher: identities, chats, messages | ~900 |
| `sinhron_net` | tokio-tungstenite WS клиент, TLS pinning, clock drift | ~600 |
| `sinhron_sync` | MLS-over-WS bridge: SyncClient, GroupHandle, HttpApi, SinhronProvider | ~1500 |
| `sinhron_cli` | headless CLI для тестирования протокола | ~430 |
| `sinhron_core` | FFI facade (cdylib для Flutter) | ~900 |
| `sinhron_server` | Axum HTTP + WS server, 7 модулей | ~3000 |

**Серверные endpoints (`/v1/...`):**
- `POST /identity` — register
- `POST /keypackages` — upload; `GET /keypackages/consume` — один или по одному с каждого устройства (`per_device`, ADR-025), подписан зарегистрированным устройством (ADR-087); `GET /keypackages/available?identities=…` — у кого их нет, ничего не забирая (перед созданием группы, tech-debt 2.34)
- `POST /groups` — announce (подпись устройства, ADR-083; с эпохой MLS создателя, ADR-090); `PUT|POST /groups/{id}/card` — карточка чата (ADR-075; своя у каждого устройства, телефон выбирает по голосам — ADR-093); `POST /groups/{id}/remove` — вычеркнуть удалённых (ADR-083); `PUT /groups/{id}/retention` — серверный таймер чата (tech-debt 2.5)
- `POST /sealed` — конверты sealed sender без аутентификации, с ключом доступа (ADR-026; с ADR-071 — ключ на собеседника, отозванный молча выбрасывается)
- `PUT /access-keys` — хэши ключей доступа на собеседника, блокировки и разблокировки (ADR-071)
- `GET|PUT /pairing/{id}` — почтовый ящик QR-привязки (ADR-027)
- `GET|POST /devices`, `DELETE /devices/{pk}` — устройства человека (ADR-025)
- `GET|PUT /sealed-keys` — ключи доставки sealed sender (ADR-023), с подписью хозяина (ADR-082)
- `POST /media`, `GET /media/{sha256}` — зашифрованные блобы (ADR-017)
- `POST /call/token`, `GET /call/turn` — LiveKit JWT и TURN (ADR-015/016)
- `POST /backup-mark` — время самой новой облачной копии аккаунта (против тихого отката, ADR-090)
- `GET /sync` — WS upgrade (Hello → Auth → Submit/SealedSubmit/Push/Resume/Welcome/Call*/Heartbeat/Ack)
- `GET /_healthz` / `GET /_readyz`

**Серверная БД:** PostgreSQL 16 + миграции `server/migrations/` (init, partitions, deliveries, pending_welcomes, groups.disappearing, media_on_disk, sealed_delivery, linked_devices, sealed_access, pairing, delivery_ttl, access_version, delivery_received, welcome_device, … , epoch_committer и backup_marks — ADR-090, group_commits — ADR-092, cards_per_device — ADR-093).

**Доказательство работы:** `client_flutter/rust/sinhron_sync/examples/full_e2e.rs` — два процесса Alice/Bob, реальный сервер + WS + HTTP. Alice шифрует "hello sinhron"; Bob расшифровывает. Прошёл.

## 3. Что НЕ построено / что отложено

### Полностью отсутствует
- **Спек-Фаза 9** — аудит, воспроизводимые сборки, подпись, дистрибуция.

### Частично реализовано / не проверено на устройствах
- **Multi-device** (§6.5, **спек-Фаза 4**) — ADR-025: свой лист MLS и сертификат у каждого устройства, `/v1/devices`, доставка на все устройства, синхронизация и отзыв; QR-привязка (ADR-027); в приложении — вход в существующий аккаунт, «Устройства». С 2026-10-18 (ADR-064) новое устройство получает **всё**: полный перенос (вся история, контакты, стикерпаки, папки, настройки чатов, заблокированные, проверенные, профиль; медиа — по ссылкам, недостающие выкладывает старое устройство) с прогрессом и продолжением после перерыва, а дальше устройства синхронизируются (`DeviceSync` в группе моих устройств); раньше — 200 последних сообщений.
