# Как установить Sinhron на Android (без Google Play)

Инструкция для человека, которому ты отправил приглашение. Подходит для любого Android 8 и новее,
в том числе Samsung Galaxy (A40 и похожие). Работает из России без VPN.

## Что прислать человеку

Ссылку-приглашение из своего Sinhron: нажми на своё фото слева вверху в «Чатах» → «Мой профиль» →
**«Поделиться, чтобы мне написали»** и отправь её любым способом, который у него работает — SMS, Telegram,
почта. Вместе со ссылкой можно переслать текст ниже.

## Текст для него (можно переслать как есть)

1. **Открой ссылку**, которую я прислал. Откроется страница Sinhron. Нажми **«Установить на Android»** —
   скачается файл `sinhron.apk` (около 60 МБ).
   *Если кнопки нет: открой в браузере `https://chat.777400777.xyz/download/sinhron.apk`.*
2. **Открой скачанный файл** (в шторке «Загрузка завершена» или в папке «Загрузки»).
   Телефон спросит, можно ли устанавливать приложения из этого браузера, — нажми **«Настройки»** и
   включи **«Разрешить из этого источника»**, затем вернись назад.
3. Нажми **«Установить»**. Если появится предупреждение Play Защиты «Неизвестное приложение» —
   нажми **«Подробнее» → «Всё равно установить»**. Это нормально: приложение не из магазина.
4. **Открой Sinhron** → «Начать» → впиши своё имя (его увижу я).
   Приложение покажет **секретные слова** — перепиши их на бумагу и убери. Без них аккаунт не вернуть,
   если телефон потеряется. Никому их не показывай.
5. **Снова нажми на мою ссылку** — Sinhron откроет чат со мной. Если вместо этого открылась страница в браузере — нажми на ней **«Открыть в приложении»**. Всё, можно писать и звонить.
6. **Чтобы звонки и сообщения приходили, даже когда приложение закрыто** (с версии 0.6.0 почти всё само):
   - разреши уведомления, когда телефон спросит;
   - на вопрос «Не ограничивать батарею для Sinhron?» — **«Разрешить»**;
   - Samsung покажет окно «Чтобы звонки доходили всегда» — нажми **«Открыть»**, потом **+**, выбери
     Sinhron и **«Добавить»** (это список «Никогда не спящие приложения»);
   - проверить: Sinhron → «Настройки» → «Уведомления» → вверху **«Звонки дойдут: да»**. Если там
     «нет — что сделать», нажми по очереди на кнопки под этой строкой.
   (До 0.6.0: «Настройки» → «Уведомления» → включи «Постоянное соединение»; Samsung: «Настройки» телефона →
   «Приложения» → Sinhron → «Батарея» → «Без ограничений».)
7. При первом звонке телефон спросит доступ к **микрофону** (и к **камере** для видео) — нажми «Разрешить».
8. *(Можно вместо «Постоянного соединения», бережёт батарею.)* **Уведомления через ntfy** — Sinhron сам
   скажет, что делать: «Настройки» → «Уведомления» → раздел **«Уведомления через ntfy»**:
   - **«Установить ntfy»** — откроется Google Play (или поставь ntfy из F-Droid);
   - **«Скопировать адрес сервера»** — адрес уже написан там же (у нас `https://push.777400777.xyz`);
   - в ntfy: меню **⋮ → «Настройки» → «Сервер по умолчанию»** → вставь адрес;
   - вернись в Sinhron и нажми **«Подключить ntfy»**. Когда всё получилось, раздел пропадает.
   Если там написано «ntfy настроен на другой сервер» — ntfy уже стоял и смотрит на ntfy.sh: сделай
   те же два последних шага.

9. **Обновления приходят сами.** Когда я выпущу новую версию, над чатами появится карточка
   «Доступно обновление» — нажми **«Обновить»**, подожди, пока скачается (там видны проценты), и нажми
   **«Установить»**. Android всегда просит это нажатие — так устроен телефон, переписка и ключи остаются.
   В самый первый раз телефон ещё спросит, можно ли Sinhron устанавливать приложения: нажми **«Настройки»**,
   включи **«Разрешить из этого источника»**, вернись назад и нажми «Установить». После установки нажми
   **«Открыть»**. Проверить вручную: «Настройки» → внизу «О приложении» → **«Проверить обновления»**.

Если на шаге 3 написано «Приложение не установлено» — скачай другой вариант:
`https://chat.777400777.xyz/download/sinhron-32bit.apk` (для старых телефонов).

## Для меня (оператора)

- Файлы лежат на сервере в `/opt/sinhron/server/download/` (`sinhron.apk` — arm64, `sinhron-32bit.apk` —
  armeabi-v7a), отдаются по `https://chat.777400777.xyz/download/…` (Caddy, deploy-guide).
- **Новая версия** (ADR-058): `bash scripts/android_release.sh`, потом `bash scripts/publish_android.sh --host root@<сервер>`
  (в `client_flutter/`). Второй скрипт заливает APK, обновляет `sinhron.apk` / `sinhron-32bit.apk` и последним —
  `android.json`; приложения (начиная с версии, где это есть) за несколько часов сами предложат обновиться.
  Первую версию с самообновлением придётся поставить ещё по ссылке, как раньше.
- Страница `/join` берёт кнопку из `SINHRON_ANDROID_INSTALL_URL` в `server/.env`.
- Push через свой ntfy включён (`https://push.777400777.xyz`). Адрес приложение берёт у сервера
  (`GET /v1/push/info` → `SINHRON_UNIFIEDPUSH_HOSTS` из `server/.env`, его пишет установщик) и само
  показывает в «Настройки» → «Уведомления» → «Уведомления через ntfy» (с версии, где это есть; запись 150
  в `docs/status.md`). Сервер принимает адреса только на этом имени — ntfy со стандартным ntfy.sh
  уведомлений не получит, раздел так и скажет. «Постоянное соединение» остаётся запасным способом
  (и единственным, если сервер без ntfy).
