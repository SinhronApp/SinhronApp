## 2026-11-13 (267) · Release: обе сборки проходят; выпуск Android — только на коммите без правок `.github/`

iPhone (запуск 7, коммит a08adba): собран и подписан ключом App Store Connect, ~14 мин. Android (запуск 4): APK собран
и подписан нашим ключом (~20 мин), но `gh release create` снова 403, хотя у токена `Contents: write`. Причина —
правило GitHub: токен сборки не может создать тег на коммите, который меняет файлы `.github/workflows/` (на это нужно
право `workflows`, его у токена не бывает). Все прошлые запуски шли на коммитах, правивших `release.yml`. Этот коммит —
только журнал; Android запущен на нём. Впредь: Release запускать на `main`, где последний коммит не трогает `.github/`.

## 2026-11-13 (266) · Release: выпуск Android на GitHub — права и очередь

Третий запуск: APK собран и подписан нашим ключом (`android.json` записан — значит, отпечаток совпал), но
`gh release create` получил 403: в организации сборкам была запрещена запись. Владелец включил «Read and write
permissions» (организация → Actions → General). Убрана общая очередь `concurrency: release` из `release.yml`: Android
ждал окончания сборки iPhone (~40 мин); две сборки Android в один час всё равно не создадут два выпуска (тот же tag).

Четвёртый запуск iPhone: ключ и после пересборки PEM не читается (`openssl pkey`) — в секрете не ключ .p8. При такой
ошибке шаг теперь печатает только форму секрета (сколько знаков, строк, есть ли строка BEGIN, сколько букв base64), не
содержимое.

Пятый запуск показал форму секрета: 257 знаков, **одна строка**, BEGIN есть, 228 букв base64 — ключ верный, но
переносы строк пропали при вставке. Сборка PEM искала тело между строками BEGIN/END и в одной строке захватывала
слова «BEGIN PRIVATE KEY» как base64. Теперь эти слова вырезаются где угодно; проверено на восьми видах (в т. ч. одна
строка с пробелами и без) и на мусоре.

Второй запуск: Xcode 26, проверка Swift и CocoaPods прошли; `xcodebuild` отверг ключ (`invalidPEMDocument`) — секрет
`ASC_KEY_P8` вставлен не в виде PEM. Шаг «App Store Connect key» в `.github/workflows/release.yml` теперь оставляет

потом `openssl pkey` — понятная ошибка до сборки. Проверено локально на сгенерированном ключе P-256 во всех шести видах
и на мусоре (отвергнут).
